# The Mouse Is Coming Too 0.1.0

Initial macOS release.

- Switch two Options+-compatible Easy-Switch devices to host 1, 2, or 3.
- Three silent app launchers for assignment through **Open Application**.
- Self-contained project code inside every app bundle.
- No debugger, UI automation, firmware changes, background daemon, or network.
- Identity-free ad-hoc signatures and a published SHA-256 checksum.

Tested with an MX Keys S and first-generation MX Master over Bluetooth. Keep a
recovery input available for the first cross-host test.
